MikeVas Workspaces — current support guide

Updated 10 November 2026. Current browser release: 5.1.1. Install the common MikeVas Connect runtime for shared-file synchronization. The historical standalone Sync Setup/helper is not the current installer. Product versions are independent.

Save, review and synchronize

  1. Save and organize selected tabs/groups as local Workspaces. Opening a saved Workspace loads its pages; installation/startup does not open them automatically.
  2. Open Settings → Open MikeVas Connect → Workspaces. Choose the shared file and explicitly enable/save shared functional settings. Theme/Popup theme remain local in each browser profile.
  3. Choose Check changes, then Review actions for the Workspace. Inspect local/shared changes and conflicts.
  4. Choose Apply and confirm the intended changes. Automatic review is a review preference, not permission to write or open pages automatically.

Local browser storage, the configured shared file and a cloud provider's delivery are separate layers. File checks passed confirms local file access/validation. It does not prove upload, reception on another computer or successful browser synchronization. Native Connected is not a sync completion.

Conflicts and uncertain outcomes

Writes use revision/CAS checks and serialization. If a write acknowledgement is lost, inspect the pending operation/recovery information before another attempt. Do not blindly retry an unknown write, overwrite the shared file or clear browser storage. An existing shared-file lock is not removed merely because it is old. Preserve unsynchronized browser edits; a backup of the shared file does not include those edits or every browser recovery journal. Cloud-provider backup/retention is separate.

Builds and support

Connect → Browsers shows the loaded version/build ID and Reload/Rebuild/unverified status. Reload the existing unpacked extension when required; do not remove it to refresh code. Settings → This Computer → Verify installation checks bundle/registrations/live builds, not cloud delivery or actual sync.

Activity contains fixed diagnostic categories. Optional diagnostic upload is controlled by Connect Settings → Tunnels and excludes workspace contents. See Privacy. Share product/version/build, action, timestamp and sanitized category; remove private URLs, titles and workspace snapshots from reports. A running Manager or Tunnels device token is not needed for Workspaces file synchronization. Physical Mac/reboot and real cloud-sync acceptance are separate from build/unit checks.
