Privacy — MikeVas SOCKS5 and MikeVas Tunnels

Version 0.2.0 — 28 October 2026

MikeVas SOCKS5 is a local desktop application. MikeVas Tunnels configures the current

browser profile's proxy and controls tunnels through a local native messaging host.

There is no developer-operated analytics, advertising or cloud account service.

Local storage and native messaging

The extension stores routing mode, destination/bypass rules, selected tunnel, theme and

a random profile identifier in local extension storage. It does not read tab titles,

page content, browsing history, search terms, cookies or login passwords.

User-requested tunnel control sends the action, tunnel identifier and browser family

to the installed Manager. The Manager returns tunnel names/endpoints, status, errors,

bypass definitions and conflicts needed for the UI. Credentials/private keys are never

sent to the extension. Browser presence reports contain browser family, a random local

profile ID, routing mode, local SOCKS port and proxy-control state. The Manager holds

these reports in memory for its Home view; they are not sent to a remote server.

For Firefox, presence reporting is optional technical/interaction data transmission to

the local native application. It requires the optional `technicalAndInteraction`

permission. Declining it disables Home browser reports but not tunnel control/routing.

Manage consent in Firefox's Permissions and data section. Chrome reports are part of

the described local Manager integration; no reports are uploaded to the developer.

Connections and diagnostics

Traffic selected for proxying is sent to your chosen SOCKS/SSH endpoint. That operator

can observe connection metadata and any unencrypted destination traffic. HTTPS remains

important. Direct and bypass destinations use your normal connection. This app is not

a VPN/kill switch and does not cover all protocols.

Desktop logs can contain application names/paths, host/IP/port, timestamps, results and

error metadata. They are saved locally with retention controls. Share diagnostic exports

only after reviewing them. SSH passwords are stored in the local encrypted master-password

vault; private keys are separate local files. Neither is included in release packages.

Public Help

Opening Help requests the public GitHub Pages website. GitHub handles normal website

request metadata under its own privacy policy. The Help URL conveys only a Light/Dark

choice; no credentials, tunnel definitions or browsing data are added to it. The site

uses no analytics, cookies, external fonts or remote script services.

Contact/issue channel: https://github.com/vassiliades/MikeVas-SOCKS5-Help/issues

Do not post passwords, keys, private hosts or unsanitized logs in public issues.
