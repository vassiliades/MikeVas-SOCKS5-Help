MikeVas Keeper — current support guide

Updated 10 November 2026. Current browser release: 5.2.1. Requires the common MikeVas Connect runtime, not the historical standalone Keeper installer. Product version numbers are independent.

First use

  1. Install Connect, then the Keeper add-on in the intended browser profile.
  2. Use Sign in. Authentication and MFA open in the Connect desktop. Do not put credentials or MFA codes in support messages.
  3. Allow/authorize the installed extension when requested. If access is denied, review the exact browser identity rather than disabling native-host checks.
  4. Open a login page and explicitly choose the Keeper fill action/record. The extension fills fields; it does not submit the form. A site may use multiple login stages.

Understand the state

Connect Connected proves the native link. Login required means the shared vault session needs authentication. Cache ready does not prove that a particular page can be filled. A successful fill does not prove website login. Keeper does not require a Tunnels device token, VPN or a running SOCKS5 Manager for its normal native vault integration.

Settings → Open MikeVas Connect opens the Keeper settings. RAM-cache duration and shortcuts can be shared after explicit enable/Save. Browser Theme and Popup theme remain local to that browser profile. Smart preload is bounded and held in RAM; never treat it as a disk password export. Logout, expiry or explicit cache clearing invalidates the shared cache/session as appropriate; already signed-in websites remain responsible for their own logout. Forgetting a preferred record does not delete a vault record.

Builds, diagnostics and recovery

Connect → Browsers shows the loaded version/build ID. Reload required refers to a different stamped payload on disk; Rebuild required means unstamped edits. Disk build not verified is not a pass. Use Reload on the existing unpacked extension, not uninstall/reinstall. Connect → Settings → This Computer → Verify installation checks registrations and loaded builds; it does not authenticate or fill a page.

Read Activity for fixed error categories and Connect Settings → Tunnels for optional diagnostic delivery. Delivered counts retained local history, not lifetime delivery. Optional upload uses the configured organization server; it is not a requirement for autofill. Privacy explains metadata and credential handling.

When native access is unavailable, confirm Connect is running, the intended browser profile/extension identity is authorized and the installed build is current. Do not install a legacy service alongside Connect. Report version/build, action, time and sanitized error category. Existing release tests are not evidence of a live vault login, every website fill or new Mac acceptance.

Ελληνικά

Εγκατάστησε το Connect και μετά το πρόσθετο. Το Sign in ανοίγει το Connect για login και MFA. Το Connect Connected επιβεβαιώνει μόνο την τοπική επικοινωνία· το Login required αφορά το vault. Επίλεξε ρητά την εγγραφή για συμπλήρωση· η φόρμα δεν υποβάλλεται αυτόματα.

Οι κοινές ρυθμίσεις RAM cache και shortcuts αλλάζουν στο Connect με ενεργοποίηση και Save. Η εμφάνιση παραμένει τοπική σε κάθε browser profile. Το Logout/clear cache αφορά την κοινή συνεδρία και δεν κάνει logout από ήδη συνδεδεμένα websites. Δεν χρειάζεται δεύτερο token ούτε ανοικτός Manager.

Στο Connect → Browsers βλέπεις το version/build που φορτώθηκε πραγματικά. Κάνε Reload στο υπάρχον πρόσθετο όταν ζητείται. Το Verify installation δεν ελέγχει πραγματικό login/autofill. Μοιράσου μόνο ασφαλείς κατηγορίες σφάλματος, ποτέ passwords, tokens, MFA ή περιεχόμενο vault.
