Linux server management

The app has separate This PC and Server sections. No personal server catalogue or credentials are included in source/release packages.

Provisioning and management access

Use an approved Linux host with OpenSSH server, systemd, Python 3, NetworkManager and a separately installed SoftEther VPN Client. Administrator review is required for packages, accounts, firewall/SELinux rules and service changes. The Windows Components page checks local components, not remote services.

`server/bootstrap.py` is a first-install administrator helper. It expects the approved SoftEther installation and a controller public key alongside it. It refuses existing accounts/installations; never use it as an upgrade command. `mva_server.py` implements the restricted JSON control plane, fixed actions and scoped resource ownership. The optional publication/egress scripts and unit examples are site-specific migration tools: review addresses, ports and allowed networks before use. They are not a general unattended installer.

In Connection settings configure host, SSH port, restricted management account, private-key path and trusted known_hosts path. Verify the host fingerprint through a trusted channel. Do not distribute actual keys, credentials, connection.json, profiles.json or diagnostic exports.

VPN and dependent SSH tunnels

Linux Auto Run enables startup when Linux boots; it is independent of Windows startup. Auto Reconnect controls retries on Linux. Overview is informational; use VPN Connections or Server SSH Tunnels for actions. Refresh performs an immediate check; Settings holds independent server status and log intervals.

VPN sessions need a working TAP adapter and address configuration. NetworkManager must use a tun connection in TAP mode, not an Ethernet connection for the SoftEther TAP device. Preserve the management network/default gateway/DNS policy. A session-established result alone does not prove network reachability. Imported profiles and credentials require an approved migration and per-profile connection/IP validation.

Use separate local 110xx and server 120xx SOCKS port ranges. They are distinct from remote SSH ports. A tunnel may reference a server VPN dependency. New SSH listeners are loopback-only. Network publication requires explicit administrator setup and source restrictions; browser clients may then reach the approved server endpoint directly. Local Windows application access can use a secure SSH relay. Linux services continue when the desktop Manager closes. The extension can reuse saved published endpoints offline, but live health and Start/Stop need management connectivity.

Delete and diagnostics

Select a row, choose Delete and confirm the current connection. This stops an active service and interrupts its users. A VPN with any dependent tunnel cannot be deleted, including a stopped dependent tunnel. Cleanup verifies ownership and removes only the selected managed resources; local backup definitions and original history remain. Partial cleanup retains an incomplete-deletion row for Retry Delete and blocks restart/edit.

The bell distinguishes This PC and Server notifications. Open Log locates the relevant record. App Logs Active Errors / Active Warnings count distinct active issues; All Records retains historical, resolved and unknown records. Server Logs contains server action results; refresh there is independent of local logs. Reading/dismissing notifications does not resolve failures.
