SOCKS5 Application Manager Help

Γρήγορη εκκίνηση — τι συνδέω πρώτα;

1. Άνοιξε το app και κάνε login με το master password. Στην πρώτη χρήση δημιουργείς master password τουλάχιστον 8 χαρακτήρων. Μετά το login ανοίγει το Home.

2. Στο SSH Tunnels έλεγξε ότι το επιθυμητό tunnel είναι ACTIVE. Αν είναι STOPPED, πάτησε Start. Το ACTIVE σημαίνει ότι ελέγχθηκαν η εκτέλεση SSH και το τοπικό SOCKS listener — όχι ότι κάθε απομακρυσμένος προορισμός είναι διαθέσιμος.

3. Επίλεξε έναν τρόπο δρομολόγησης: Applications για μια εφαρμογή ή το πρόσθετο για τον browser. Μην ενεργοποιείς και τους δύο τρόπους για τον ίδιο browser. Η εφαρμογή παραμένει διαθέσιμη στο system tray.

SSH server, SOCKS και Destination

SSH server είναι ο απομακρυσμένος υπολογιστής στον οποίο συνδέεσαι με username και SSH Key ή Password. Το SSH port αφορά εκείνον τον server.

Local SOCKS είναι η τοπική είσοδος του tunnel, π.χ. 127.0.0.1:1080. Αυτό το port χρησιμοποιεί ο browser ή το proxy profile. Δεν είναι το SSH port.

Destination είναι το site ή η υπηρεσία που θέλεις να φτάσεις μέσα από το tunnel. Μπορεί να είναι άλλος υπολογιστής από τον SSH server. Παράδειγμα: browser → 127.0.0.1:1080 → SSH server → destination.

Οι σελίδες της εφαρμογής

Home: σύνοψη driver, routing, tunnels, συνδέσεων και ενεργών προβλημάτων. Applications: δρομολόγηση ανά εφαρμογή. Proxy Settings: διαθέσιμα SOCKS5 profiles και Direct / Bypass.

SSH Tunnels: δημιουργία και διαχείριση SSH συνδέσεων. Driver: κατάσταση και χειρισμός WinDivert. Logs: ενέργειες, αιτίες αποτυχίας και ιστορικό. Advanced: χρόνοι ανανέωσης, εκκίνηση, ειδοποιήσεις, ασφάλεια και μεταφορά ρυθμίσεων.

Driver Running, Routing active και SSH ACTIVE είναι διαφορετικές καταστάσεις. Ο driver μπορεί να τρέχει χωρίς ενεργή δρομολόγηση. Ένα tunnel μπορεί να είναι ACTIVE χωρίς ο browser να το χρησιμοποιεί.

Η αλλαγή Light / Dark γίνεται από το εικονίδιο ήλιου/φεγγαριού δίπλα στο ? της σταθερής κεφαλίδας και αποθηκεύεται αμέσως.

Προσθήκη SSH tunnel

SSH Tunnels → Add SSH Tunnel. Συμπλήρωσε όνομα, μοναδικό Local SOCKS port, SSH host, SSH port και SSH username. Το Password αφορά αυτόν τον χρήστη, π.χ. root.

Επίλεξε SSH Key με διαδρομή ιδιωτικού κλειδιού ή Password. Το Save ελέγχει authentication και δημιουργεί τη διαχείριση του tunnel. Αν ζητηθεί Trust & Continue, επαλήθευσε πρώτα το fingerprint από έμπιστη πηγή. Μην αποδέχεσαι ανεξήγητη αλλαγή host key.

Το Start after saving ξεκινά τη σύνδεση αμέσως. Το Auto Run και το Auto Reconnect είναι ξεχωριστές επιλογές. Μην χρησιμοποιείς το ίδιο τοπικό port σε δύο tunnels ή άλλες εφαρμογές.

Start / Stop / Restart και έλεγχοι

Start ξεκινά το κοινό SSH tunnel. Stop το σταματά για όλους όσοι το χρησιμοποιούν. Restart διακόπτει και ξαναξεκινά το tunnel. Τα κουμπιά ενεργοποιούνται ανάλογα με την κατάστασή του.

Test Connection επανελέγχει την κατάσταση του tunnel. Destination Check αφορά συγκεκριμένη IP και TCP port μέσα από το SOCKS: επαληθεύει TCP πρόσβαση, όχι πλήρη λειτουργία ιστοσελίδας ή login. Όταν έχει οριστεί, επανελέγχεται περίπου κάθε λεπτό κατά τους ελέγχους του ενεργού tunnel.

Browser Stop Protection On απαγορεύει Stop από το πρόσθετο. Το Stop μέσα στο app παραμένει διαθέσιμο. Last healthy είναι ο χρόνος της τελευταίας γνωστής επιτυχίας, όχι εγγύηση ότι η σύνδεση είναι ακόμη ενεργή.

Τι κάνει αυτόματα

Proxy Profiles: έλεγχος των ενεργοποιημένων profiles στο διάστημα του Advanced. Home: περιοδική ενημέρωση όταν είναι ανοιχτό. Driver: ανεξάρτητη αντίστροφη μέτρηση που συνεχίζεται όταν αλλάζεις μενού ή κρύβεις το app.

Τα tunnels έχουν δικό τους supervisor και ελέγχους SOCKS. Με Auto Reconnect επανασυνδέονται μετά από αποτυχίες δικτύου. Η αναμονή αυξάνεται από τον επιλεγμένο αρχικό χρόνο έως 10 λεπτά, ή μεγαλύτερο αρχικό χρόνο αν έχει οριστεί, και επανέρχεται μετά από 60 δευτερόλεπτα σταθερής σύνδεσης.

Κατά την αναμονή δικτύου γίνεται επανέλεγχος ανά 5 δευτερόλεπτα. Μεγάλο κενό επιτήρησης, όπως sleep, προκαλεί νέο έλεγχο πρόσβασης στον SSH server. Η ανίχνευση απώλειας μιας ήδη ενεργής SSH σύνδεσης χρησιμοποιεί και τα OpenSSH keepalives και δεν είναι στιγμιαία.

Λάθος authentication, άγνωστο/αλλαγμένο host key, πρόβλημα ιδιωτικού key, SSH configuration/algorithm ή κατειλημμένο local port σταματούν τις επαναλήψεις. Διόρθωσε την αιτία και πάτησε Start. Κάθε tunnel έχει προστασία από διπλές εκκινήσεις.

Οι νέες εκδόσεις του supervisor φορτώνονται στο επόμενο Start / Restart του tunnel. Δεν αντικαθιστούν την εκτέλεση ενός ήδη ενεργού tunnel στη μέση της σύνδεσης.

Windows startup, Auto Run και tray

Advanced → Start with Windows ξεκινά το app. Start minimized το εμφανίζει στο tray. Το Auto Run κάθε SSH tunnel είναι ξεχωριστό: καθορίζει αν το tunnel ξεκινά με το login στα Windows.

SSH Key χωρίς passphrase μπορεί να ξεκινά χωρίς master login, όταν το key και το task είναι έτοιμα. Password tunnel χρειάζεται ξεκλείδωτο vault από το app· πριν από αυτό περιμένει σε LOCKED. Το Auto Reconnect δεν ενεργοποιεί από μόνο του το Auto Run.

Το Χ κρύβει το app στο tray. Exit το κλείνει πραγματικά. Τα ανεξάρτητα scheduled SSH tunnels μπορούν να συνεχίζουν, αλλά το πρόσθετο δεν μπορεί να κάνει Start / Stop ή να πάρει νέα στοιχεία χωρίς το Manager. Οι ήδη εφαρμοσμένοι κανόνες browser παραμένουν.

Applications και Proxy Profiles

Proxy Settings → Add Proxy Profile: δώσε το SOCKS5 host και port. Για τοπικό SSH tunnel είναι συνήθως 127.0.0.1 και το Local SOCKS port. Το OK ενός profile αφορά τον έλεγχο του SOCKS endpoint.

Applications → Add Application: επίλεξε executable και proxy profile. Connect ενεργοποιεί δρομολόγηση για τη συγκεκριμένη εφαρμογή. Προαιρετικά όρισε IP / networks που θα πάνε μέσω proxy· οι υπόλοιποι προορισμοί μένουν Direct.

Για το ίδιο executable μπορείς να έχεις διαφορετικές ονομασμένες εγγραφές. Όταν άλλη εγγραφή είναι ήδη ενεργή, το popup Cancel / Switch ελέγχει πρώτα το νέο proxy και μετά αλλάζει τη δρομολόγηση. Δεν ξεχωρίζει δύο ταυτόχρονες εκτελέσεις του ίδιου executable ως ανεξάρτητα profiles.

Check Connection παρουσιάζει διαγνωστικά χωρίς να ξεκινά tunnel. Η δρομολόγηση του desktop καλύπτει TCP/IPv4 και χρησιμοποιεί το τοπικό DNS. UDP και IPv6 δεν δρομολογούνται από αυτόν τον μηχανισμό. Το Driver και το routing ελέγχονται ξεχωριστά.

Πρόσθετο browser — Connect / Disconnect

Άνοιξε το MikeVas Tunnels στον browser. Το app πρέπει να τρέχει, ακόμη και κρυμμένο στο tray. Η ένδειξη Manager offline κρύβει τις επιλογές διαχείρισης. Κάθε browser/profile έχει δικές του ρυθμίσεις και ανεξάρτητο Light / Dark.

Manage SSH tunnel → Choose tunnel: επίλεξε από το popup. Τα Start / Stop αφορούν το κοινό tunnel, όχι μόνο τον browser. Η γραμμή Tunnel στην κύρια οθόνη είναι μόνο ένδειξη.

Traffic rules: All sites via tunnel ή Selected IPs / sites. Στη δεύτερη επιλογή βάλε μία IP, CIDR ή domain ανά γραμμή. Οι IP κανόνες ταιριάζουν σε URL με κυριολεκτική IP· πρόσθεσε domain για site που ανοίγεις με όνομα.

Connect εφαρμόζει τη ρύθμιση σε όλο το συγκεκριμένο browser profile. Disconnect επιλέγει Direct μόνο για αυτόν τον browser, χωρίς να σταματά το κοινό tunnel. Όσο είναι συνδεδεμένος ο browser, αποσυνδέσου πρώτα για αλλαγή tunnel ή κανόνων. Κάνε Reload στη σελίδα για νέες συνδέσεις.

Browser connected σημαίνει επιβεβαιωμένη ρύθμιση του πρόσθετου και ενεργό tunnel. Η κινούμενη τελεία δείχνει κατεύθυνση δρομολόγησης, όχι πραγματική καταμέτρηση πακέτων. Αν το tunnel δεν επαληθεύεται, εμφανίζεται προειδοποίηση και δεν γίνεται αυτόματο Direct fallback.

Direct / Bypass και κανόνες

Bypass είναι εξαιρέσεις που βγαίνουν Direct ακόμη και όταν έχει επιλεγεί proxy. Διαχειρίζονται από Proxy Settings → Direct / Bypass. Δεν είναι λίστα προορισμών που πρέπει να πάνε μέσα στο SOCKS.

Στο πρόσθετο το Follow app bypass είναι ενεργό από προεπιλογή. View bypass rules δείχνει τη λίστα. Αν το απενεργοποιήσεις πριν από Connect, το συγκεκριμένο browser αγνοεί αυτές τις εξαιρέσεις. Localhost / loopback παραμένουν πάντα Direct.

Οι αλλαγές στα app bypass δεν ξαναγράφουν αυτόματα ήδη εφαρμοσμένους κανόνες browser. Για νέα ρύθμιση κάνε Disconnect και Connect. Το Restore browser settings στις πληροφορίες κανόνων αφαιρεί τη ρύθμιση του πρόσθετου και επιστρέφει στις ρυθμίσεις συστήματος — δεν σημαίνει υποχρεωτικά Direct.

Master password, logout και SSH Key

Το master password ξεκλειδώνει το app και το κρυπτογραφημένο vault των SSH passwords. Δεν είναι το root/SSH password. Advanced → Security → Change Master Password αλλάζει το master με ελάχιστο 8 χαρακτήρες. Κράτησέ το με ασφάλεια: δεν υπάρχει ανάκτηση ξεχασμένου master.

Automatic logout σε λεπτά αδράνειας κλειδώνει την πρόσβαση στο app, ενώ routing, tunnels και Auto Reconnect συνεχίζουν. Το login ξανανοίγει το Home. Το πλήρες Exit ή restart υπολογιστή απαιτεί νέο ξεκλείδωμα για Password tunnels.

Μετατροπή Password σε SSH Key: σύνδεσε πρώτα επιτυχώς το Password tunnel και χρησιμοποίησε τη μετατροπή της εγγραφής. Εγκαθίσταται δημόσιο key, ελέγχεται ανεξάρτητη σύνδεση με key και μόνο μετά την επιτυχημένη επανασύνδεση αφαιρείται το αποθηκευμένο password του tunnel. Το password του απομακρυσμένου χρήστη δεν διαγράφεται.

Logs και αντιμετώπιση προβλημάτων

Logs εμφανίζει την ενέργεια, τον προορισμό, το αποτέλεσμα και την αιτία. Χρησιμοποίησε αναζήτηση, Errors / Warnings και φίλτρο κατάστασης. Active είναι επιβεβαιωμένο ενεργό πρόβλημα, Resolved επιλύθηκε μετά από έλεγχο, Unknown χρειάζεται νέο έλεγχο και Historical είναι ιστορική καταγραφή. Η επίλυση δεν διαγράφει το αρχικό σφάλμα.

LOCKED: κάνε master login. Authentication rejected: έλεγξε SSH username και Password / Key. Local port occupied: έλεγξε αν άλλο tunnel ή πρόγραμμα χρησιμοποιεί το port. Host key changed: επιβεβαίωσε την ταυτότητα του server πριν εμπιστευτείς νέο key.

Waiting for network / timeout: έλεγξε σύνδεση, SSH host/port και firewall. Το ACTIVE χωρίς πρόσβαση σε site χρειάζεται Destination Check προς τη σωστή υπηρεσία. Για αποκλεισμό από firewall έλεγξε την καταγραφή του firewall· μην απενεργοποιείς συνολικά την προστασία.

Manager offline στο πρόσθετο: άνοιξε το app και πάτησε Refresh. Αν άλλη επέκταση ή policy ελέγχει το proxy, η εφαρμογή δεν την παρακάμπτει. Αν υπάρχει desktop routing για τον ίδιο browser, επίλεξε έναν μηχανισμό και ακολούθησε το μήνυμα σύγκρουσης.

Clear Session καθαρίζει την προβολή συνεδρίας, όχι τα αποθηκευμένα log files. Open Log Folder και Export βοηθούν στη διάγνωση. Η διατήρηση/περιστροφή logs ορίζεται στο Advanced.

Μεταφορά, ενημέρωση και όρια

Advanced → Import / Export μεταφέρει ορισμούς ρυθμίσεων. Η μεταφορά αποθηκευμένων passwords είναι ξεχωριστή και κρυπτογραφημένη. Τα private keys δεν περιλαμβάνονται. Τα εισαγόμενα tunnels χρειάζονται Edit / Save με τα τοπικά credentials και έλεγχο ταυτότητας πριν ξεκινήσουν.

Στα Windows τα δεδομένα αποθηκεύονται κάτω από %LOCALAPPDATA%\MikeVas_SOCKS5, ανεξάρτητα από τον φάκελο της εφαρμογής. Το Advanced → Open Settings Folder ανοίγει τον σωστό φάκελο. Αν ζητηθεί ξαφνικά νέο master password σε υπάρχουσα εγκατάσταση, μην δημιουργήσεις άλλο πριν ελεγχθεί η διαδρομή δεδομένων.

Μετά από αλλαγές του unpacked πρόσθετου κάνε Extensions → Reload σε κάθε browser. Οι υπάρχουσες ρυθμίσεις αποθηκεύονται ανά browser profile. Η μόνιμη εγκατάσταση Firefox χρειάζεται υπογραφή Mozilla· προσωρινό πρόσθετο χάνεται μετά από restart του Firefox. Αλλαγές proxy στο Firefox απαιτούν Allow in private windows.

Τα reports browser στο Home είναι πρόσφατες αναφορές, όχι λίστα ανοιχτών tabs. Μπορεί να μείνουν προσωρινά μετά το κλείσιμο browser και μετά χαρακτηρίζονται μη επιβεβαιωμένα. Δεν περιέχουν ιστορικό περιήγησης ή passwords.

Η τρέχουσα υλοποίηση διαχείρισης driver και scheduled SSH είναι για Windows. Το macOS παραμένει μελλοντικό στάδιο· δεν θεωρείται ολοκληρωμένη ή δοκιμασμένη λειτουργία.

Components και υγεία μηχανισμών

Το Components ελέγχει OpenSSH Client, .NET 10 και Python. Available σημαίνει επιτυχημένο έλεγχο, ενώ Missing ή Error χρειάζεται προσοχή. Το .NET εκτελεί το app· OpenSSH και Python χρησιμοποιούνται όταν χρειάζονται. Δεν είναι υπηρεσίες με ξεχωριστό Start. Χρησιμοποίησε την ενέργεια εγκατάστασης ή αποκατάστασης της κάρτας.

Η κάτω μπάρα δείχνει τα αποτελέσματα σε όλα τα μενού. Έλεγχος γίνεται στην εκκίνηση, κάθε πέντε λεπτά και με Check. Ο driver είναι ανεξάρτητος από το routing. Το Start with Windows ανοίγει το app στο Windows login· κάθε tunnel έχει δικό του Auto Run. Το Auto Reconnect δεν αντικαθιστά το Auto Run.

Κάτω από το όνομα του πρόσθετου φαίνεται Mechanisms healthy, Not fully verified ή Needs attention. Με κλικ βλέπεις επικοινωνία Manager/native bridge, πρόσφατους ελέγχους components, πραγματικό έλεγχο proxy του browser, συγκρούσεις και υγεία SOCKS του ενεργού tunnel. Παλιό app χωρίς στοιχεία υγείας δεν χαρακτηρίζεται υγιές. Κλειστά tunnels που δεν χρησιμοποιούνται δεν επηρεάζουν τον browser σε Direct.

Ο WinDivert εμφανίζεται πληροφοριακά: δεν χρειάζεται για SSH routing από το πρόσθετο. Το πράσινο δεν επιβεβαιώνει internet ή όλους τους προορισμούς· χρησιμοποίησε Destination Check για συγκεκριμένο στόχο. Οι έλεγχοι δεν εγκαθιστούν λογισμικό ούτε αλλάζουν αυτόματα το routing.

Παλιός τερματισμός launcher από προηγούμενη εκκίνηση Windows εμφανίζεται ως Stopped όταν το αποτέλεσμα είναι ιστορικό. Ρητά σφάλματα SSH και αποτυχίες της τρέχουσας εκκίνησης παραμένουν Error. Το αρχικό ιστορικό logs διατηρείται.

Quick start — what connects first?

1. Open the app and log in with your master password. On first use, create a master password of at least 8 characters. Successful login opens Home.

2. In SSH Tunnels, check that your tunnel is ACTIVE. If it is STOPPED, choose Start. ACTIVE verifies the SSH process and local SOCKS listener; it does not prove every remote destination is reachable.

3. Choose one routing method: Applications for an application, or the extension for a browser. Do not enable both for the same browser. Keep the Manager available in the system tray.

SSH server, SOCKS and Destination

The SSH server is the remote computer you authenticate to using a username and SSH Key or Password. SSH port belongs to that remote service.

Local SOCKS is the tunnel's local entry point, such as 127.0.0.1:1080. Your browser or proxy profile uses this port. It is not the SSH port.

A Destination is the site or service you want to reach through the tunnel. It may be a different computer from the SSH server: browser → 127.0.0.1:1080 → SSH server → destination.

Application pages

Home summarizes the driver, routing, tunnels, connections and active issues. Applications controls routing per application. Proxy Settings manages SOCKS5 profiles and Direct / Bypass.

SSH Tunnels creates and manages SSH connections. Driver controls and checks WinDivert. Logs shows operations, failure reasons and history. Advanced contains refresh timing, startup, notifications, security and configuration transfer.

Driver Running, Routing active and SSH ACTIVE are separate states. The driver can run without application routing. A tunnel can be ACTIVE while your browser is still Direct.

Switch Light / Dark using the sun/moon icon beside ? in the fixed header. The preference is saved immediately.

Add an SSH tunnel

SSH Tunnels → Add SSH Tunnel. Enter a name, unique Local SOCKS port, SSH host, SSH port and SSH username. Password authenticates that username, for example root.

Choose SSH Key with a private key path, or Password. Save validates authentication and sets up tunnel management. If Trust & Continue appears, verify the fingerprint through a trusted source first. Do not accept an unexplained host key change.

Start after saving starts the connection immediately. Auto Run and Auto Reconnect are separate options. Do not reuse a local port for two tunnels or another application.

Start / Stop / Restart and checks

Start launches the shared SSH tunnel. Stop stops it for everyone using it. Restart disconnects and starts it again. Buttons are enabled according to the current state.

Test Connection rechecks tunnel status. Destination Check tests a specific IP and TCP port through SOCKS: it verifies TCP reachability, not a complete website response or login. When configured, it is rechecked about once a minute during active tunnel checks.

Browser Stop Protection On prevents Stop from the extension. Desktop Stop remains available. Last healthy is the last known successful check, not a guarantee the tunnel is still active.

What runs automatically

Proxy Profiles checks enabled profiles at the interval set in Advanced. Home refreshes periodically while open. Driver has its own countdown that continues when you change menus or hide the app.

Tunnels have their own supervisor and SOCKS checks. With Auto Reconnect they reconnect after network failures. Delays increase from the configured initial value up to 10 minutes, or a larger configured base, and reset after 60 seconds of stable connection.

While waiting for the network, reachability is rechecked every 5 seconds. A long monitoring gap, such as sleep, triggers a new SSH server reachability check. Loss of an established SSH session also relies on OpenSSH keepalives and is not detected instantly.

Authentication failure, unknown/changed host key, private key problems, SSH configuration/algorithm failures and local port conflicts pause retries. Correct the cause and press Start. Each tunnel is protected against duplicate starts.

New supervisor versions load on the next Start / Restart of each tunnel. They do not replace an already running supervisor mid-connection.

Windows startup, Auto Run and tray

Advanced → Start with Windows starts the app. Start minimized puts it in the tray. Each SSH tunnel's Auto Run is separate and determines whether that tunnel starts at Windows login.

An SSH Key without a passphrase can start without master login when the key and task are ready. Password tunnels need the app's unlocked vault; until then they wait in LOCKED. Auto Reconnect does not enable Auto Run.

X hides the app to the tray. Exit really closes it. Independent scheduled SSH tunnels may keep running, but the extension cannot Start / Stop or fetch fresh status without the Manager. Existing browser routing rules remain configured.

Applications and Proxy Profiles

Proxy Settings → Add Proxy Profile: enter the SOCKS5 host and port. For a local SSH tunnel, these are normally 127.0.0.1 and the Local SOCKS port. A profile's OK status checks the SOCKS endpoint.

Applications → Add Application: select an executable and proxy profile. Connect enables routing for that application. Optionally specify IPs/networks to send through the proxy; other destinations stay Direct.

You can create differently named entries for the same executable. When another entry is active, Cancel / Switch checks the new proxy before changing routing. This does not give two simultaneous instances of the same executable independent profiles.

Check Connection presents diagnostics without starting a tunnel. Desktop routing covers TCP/IPv4 and uses local DNS. UDP and IPv6 are outside this routing mechanism. Driver and routing are controlled separately.

Browser extension — Connect / Disconnect

Open MikeVas Tunnels in your browser. The app must be running, including hidden in the tray. Manager offline hides management choices. Each browser/profile has its own settings and independent Light / Dark preference.

Manage SSH tunnel → Choose tunnel: select an entry in the popup. Start / Stop affects the shared tunnel, not just this browser. The main Tunnel row is read-only.

Traffic rules offers All sites via tunnel or Selected IPs / sites. For selected sites enter one IP, CIDR or domain per line. IP rules match literal IP URLs; add domains for sites you access by name.

Connect applies routing throughout this browser profile. Disconnect chooses Direct only for this browser and keeps the shared tunnel running. Disconnect before changing the tunnel or routing rules. Reload web pages to establish new connections.

Browser connected means the extension's routing is verified and its tunnel is active. The moving dot illustrates routing direction; it is not a live packet counter. An unverified tunnel shows a warning and does not trigger automatic Direct fallback.

Direct / Bypass and rules

Bypass entries are exceptions that use Direct even when a proxy is selected. Manage them in Proxy Settings → Direct / Bypass. They are not the list of destinations to send through SOCKS.

The extension's Follow app bypass is enabled by default. View bypass rules displays the list. Uncheck it before Connect to ignore those app exceptions in this browser. Localhost / loopback always stays Direct.

Changing app bypass does not automatically rewrite an already applied browser policy. Disconnect and Connect to apply the new snapshot. Restore browser settings in rule information removes this extension's settings and returns to system settings; that is not necessarily Direct.

Master password, logout and SSH Key

The master password unlocks the app and encrypted SSH password vault. It is not your root/SSH password. Advanced → Security → Change Master Password changes it, with a minimum of 8 characters. Keep it safe: a forgotten master password cannot be recovered.

Automatic logout after inactivity locks app access while routing, tunnels and Auto Reconnect continue. Login returns to Home. Full Exit or a computer restart requires a fresh unlock for Password tunnels.

To convert Password to SSH Key, first connect the Password tunnel successfully and use its conversion action. The public key is installed, independent key authentication is verified, and the saved tunnel password is removed only after successful reconnection. The remote user's password is not deleted.

Logs and troubleshooting

Logs shows the operation, destination, result and reason. Use search, Errors / Warnings and lifecycle filters. Active is a confirmed current issue; Resolved passed a later verification; Unknown needs a fresh check; Historical is retained activity. Resolution does not delete the original error.

LOCKED: log in with the master password. Authentication rejected: check SSH username and Password / Key. Local port occupied: check for another tunnel or program using that port. Host key changed: verify server identity before trusting the new key.

Waiting for network / timeout: check connectivity, SSH host/port and firewall. ACTIVE without website access calls for a Destination Check to the correct service. Review firewall logs for blocks; do not disable all protection.

Manager offline in the extension: start the app and choose Refresh. Another extension or policy controlling the proxy is not overridden. If desktop routing is active for the same browser, select one routing method and follow the conflict message.

Clear Session clears the session view, not saved log files. Open Log Folder and Export help diagnosis. Advanced controls log retention and rotation.

Transfer, updates and current limits

Advanced → Import / Export transfers configuration definitions. Saved password transfer is separate and encrypted. Private keys are not included. Imported tunnels require Edit / Save with local credentials and identity verification before starting.

On Windows, data is stored under %LOCALAPPDATA%\MikeVas_SOCKS5, independently of the application folder. Advanced → Open Settings Folder opens the correct location. If an existing installation suddenly asks for a new master password, do not create another before checking its data location.

After unpacked extension updates, use Extensions → Reload in each browser. Settings are stored per browser profile. Permanent Firefox installation requires Mozilla signing; a temporary add-on is removed by Firefox restart. Firefox proxy changes require Allow in private windows.

Browser reports on Home are recent reports, not a list of open tabs. They can remain briefly after a browser closes, then become unverified. They contain no browsing history or passwords.

The current driver and scheduled SSH management implementation targets Windows. macOS remains a future stage and is not a completed or verified implementation.

Components and mechanism health

Components checks OpenSSH Client, .NET 10 and Python. Available means the component was verified; Missing or Error requires attention. .NET runs this app, while OpenSSH and Python run on demand. They are not services with separate Start buttons. Use the installation or repair action shown on the component card.

The bottom status bar shows component results on every page. Checks run at startup, every five minutes and when you choose Check. Driver state is separate from routing. Start with Windows launches the app at Windows sign-in; each tunnel has its own Auto Run setting. Auto Reconnect does not replace Auto Run.

The browser extension shows Mechanisms healthy, Not fully verified or Needs attention under its name. Click the indicator for Manager/native bridge, component freshness, effective browser proxy control, conflicts and the active tunnel SOCKS health. An old Manager without health data is not marked healthy. Stopped tunnels not in use do not make a Direct browser unhealthy.

WinDivert is shown for information: browser extension SSH routing does not require it. Green health does not prove internet access or every destination; use Destination Check for a specific target. Local checks do not install software or change routing automatically.

A stopped launcher from an earlier Windows session is shown as Stopped when its termination result is historical. Explicit SSH errors and failures in the current session remain Error; the original log history is retained.
