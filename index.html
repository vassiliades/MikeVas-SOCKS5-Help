SOCKS5 Application Manager Help

Γρήγορη εκκίνηση — τι συνδέω πρώτα;

1. Άνοιξε το app και κάνε login με το master password. Στην πρώτη χρήση δημιουργείς master password τουλάχιστον 8 χαρακτήρων. Μετά το login ανοίγει το Home.

2. Στο SSH Tunnels έλεγξε ότι το επιθυμητό tunnel είναι ACTIVE. Αν είναι STOPPED, πάτησε Start. Το ACTIVE σημαίνει ότι ελέγχθηκαν η εκτέλεση SSH και το τοπικό SOCKS listener — όχι ότι κάθε απομακρυσμένος προορισμός είναι διαθέσιμος.

3. Επίλεξε έναν τρόπο δρομολόγησης: Applications για μια εφαρμογή ή το πρόσθετο για τον browser. Μην ενεργοποιείς και τους δύο τρόπους για τον ίδιο browser. Η εφαρμογή παραμένει διαθέσιμη στο system tray.

SSH server, SOCKS και Destination

SSH server είναι ο απομακρυσμένος υπολογιστής στον οποίο συνδέεσαι με username και SSH Key ή Password. Το SSH port αφορά εκείνον τον server.

Local SOCKS είναι η τοπική είσοδος του tunnel, π.χ. 127.0.0.1:11080. Αυτό το port χρησιμοποιεί ο browser ή το proxy profile. Δεν είναι το SSH port.

Destination είναι το site ή η υπηρεσία που θέλεις να φτάσεις μέσα από το tunnel. Μπορεί να είναι άλλος υπολογιστής από τον SSH server. Παράδειγμα: browser → 127.0.0.1:11080 → SSH server → destination.

Οι σελίδες της εφαρμογής

Το Home / Network συνδυάζει local και Linux server κατάσταση. Τα This PC Overview και Server Overview δείχνουν τις δικές τους πληροφορίες. Το Application Routing ελέγχει κανόνες εφαρμογών Windows, το Apps & Browsers δείχνει αναφορές συνδέσεων και το Proxy Profiles διαχειρίζεται SOCKS5 profiles και Direct / Bypass.

Το Local SSH Tunnels διαχειρίζεται SSH συνδέσεις Windows. Η ενότητα Server διαχειρίζεται ξεχωριστά VPN, SSH tunnels και server logs. Το Driver ελέγχει WinDivert και το Components τα τοπικά runtimes. Τα App Logs κρατούν διαγνωστικά και το Settings περιλαμβάνει refresh, startup, ειδοποιήσεις, ασφάλεια και μεταφορά.

Driver Running, Routing active και SSH ACTIVE είναι διαφορετικές καταστάσεις. Ο driver μπορεί να τρέχει χωρίς ενεργή δρομολόγηση. Ένα tunnel μπορεί να είναι ACTIVE χωρίς ο browser να το χρησιμοποιεί.

Η αλλαγή Light / Dark γίνεται από το εικονίδιο ήλιου/φεγγαριού δίπλα στο εικονίδιο βιβλίου Help της σταθερής κεφαλίδας και αποθηκεύεται αμέσως.

Προσθήκη SSH tunnel

SSH Tunnels → Add SSH Tunnel. Συμπλήρωσε όνομα, μοναδικό Local SOCKS port, SSH host, SSH port και SSH username. Το Password αφορά αυτόν τον χρήστη, π.χ. root.

Επίλεξε SSH Key με διαδρομή ιδιωτικού κλειδιού ή Password. Το Save ελέγχει authentication και δημιουργεί τη διαχείριση του tunnel. Αν ζητηθεί Trust & Continue, επαλήθευσε πρώτα το fingerprint από έμπιστη πηγή. Μην αποδέχεσαι ανεξήγητη αλλαγή host key.

Το Start after saving ξεκινά τη σύνδεση αμέσως. Το Auto Run και το Auto Reconnect είναι ξεχωριστές επιλογές. Μην χρησιμοποιείς το ίδιο τοπικό port σε δύο tunnels ή άλλες εφαρμογές.

Start / Stop / Restart και έλεγχοι

Start ξεκινά το κοινό SSH tunnel. Stop το σταματά για όλους όσοι το χρησιμοποιούν. Restart διακόπτει και ξαναξεκινά το tunnel. Τα κουμπιά ενεργοποιούνται ανάλογα με την κατάστασή του.

Test Connection επανελέγχει την κατάσταση του tunnel. Destination Check αφορά συγκεκριμένη IP και TCP port μέσα από το SOCKS: επαληθεύει TCP πρόσβαση, όχι πλήρη λειτουργία ιστοσελίδας ή login. Όταν έχει οριστεί, επανελέγχεται περίπου κάθε λεπτό κατά τους ελέγχους του ενεργού tunnel.

Browser Stop Protection On απαγορεύει Stop από το πρόσθετο. Το Stop μέσα στο app παραμένει διαθέσιμο. Last healthy είναι ο χρόνος της τελευταίας γνωστής επιτυχίας, όχι εγγύηση ότι η σύνδεση είναι ακόμη ενεργή.

Τι κάνει αυτόματα

Proxy Profiles: έλεγχος των ενεργοποιημένων profiles στο διάστημα του Settings. Home: περιοδική ενημέρωση όταν είναι ανοιχτό. Driver: ανεξάρτητη αντίστροφη μέτρηση που συνεχίζεται όταν αλλάζεις μενού ή κρύβεις το app.

Τα local tunnels Windows έχουν δικό τους supervisor και ελέγχους SOCKS. Με Auto Reconnect επαναλαμβάνουν τη σύνδεση μετά από αποτυχίες δικτύου. Η καθυστέρηση αυξάνεται από την αρχική ρύθμιση έως 10 λεπτά ή μεγαλύτερη ρυθμισμένη βάση και μηδενίζεται μετά από 60 δευτερόλεπτα σταθερής σύνδεσης. Τα server retries διαχειρίζονται ξεχωριστά στον Linux.

Κατά την αναμονή δικτύου γίνεται επανέλεγχος ανά 5 δευτερόλεπτα. Μεγάλο κενό επιτήρησης, όπως sleep, προκαλεί νέο έλεγχο πρόσβασης στον SSH server. Η ανίχνευση απώλειας μιας ήδη ενεργής SSH σύνδεσης χρησιμοποιεί και τα OpenSSH keepalives και δεν είναι στιγμιαία.

Λάθος authentication, άγνωστο/αλλαγμένο host key, πρόβλημα ιδιωτικού key, SSH configuration/algorithm ή κατειλημμένο local port σταματούν τις επαναλήψεις. Διόρθωσε την αιτία και πάτησε Start. Κάθε tunnel έχει προστασία από διπλές εκκινήσεις.

Οι νέες εκδόσεις του supervisor φορτώνονται στο επόμενο Start / Restart του tunnel. Δεν αντικαθιστούν την εκτέλεση ενός ήδη ενεργού tunnel στη μέση της σύνδεσης.

Windows startup, Auto Run και tray

Settings → Start with Windows ξεκινά το app. Start minimized το εμφανίζει στο tray. Το Auto Run κάθε SSH tunnel είναι ξεχωριστό: καθορίζει αν το tunnel ξεκινά με το login στα Windows.

SSH Key χωρίς passphrase μπορεί να ξεκινά χωρίς master login, όταν το key και το task είναι έτοιμα. Password tunnel χρειάζεται ξεκλείδωτο vault από το app· πριν από αυτό περιμένει σε LOCKED. Το Auto Reconnect δεν ενεργοποιεί από μόνο του το Auto Run.

Το Χ κρύβει το app στο tray. Exit το κλείνει πραγματικά. Τα ανεξάρτητα scheduled SSH tunnels μπορούν να συνεχίζουν, αλλά το πρόσθετο δεν μπορεί να κάνει Start / Stop ή να πάρει νέα στοιχεία χωρίς το Manager. Οι ήδη εφαρμοσμένοι κανόνες browser παραμένουν.

Applications και Proxy Profiles

Proxy Profiles → Add Proxy Profile: δώσε το SOCKS5 host και port. Για τοπικό SSH tunnel είναι συνήθως 127.0.0.1 και το Local SOCKS port. Το OK ενός profile αφορά τον έλεγχο του SOCKS endpoint.

Applications → Add Application: επίλεξε executable και proxy profile. Connect ενεργοποιεί δρομολόγηση για τη συγκεκριμένη εφαρμογή. Προαιρετικά όρισε IP / networks που θα πάνε μέσω proxy· οι υπόλοιποι προορισμοί μένουν Direct.

Για το ίδιο executable μπορείς να έχεις διαφορετικές ονομασμένες εγγραφές. Όταν άλλη εγγραφή είναι ήδη ενεργή, το popup Cancel / Switch ελέγχει πρώτα το νέο proxy και μετά αλλάζει τη δρομολόγηση. Δεν ξεχωρίζει δύο ταυτόχρονες εκτελέσεις του ίδιου executable ως ανεξάρτητα profiles.

Check Connection παρουσιάζει διαγνωστικά χωρίς να ξεκινά tunnel. Η δρομολόγηση του desktop καλύπτει TCP/IPv4 και χρησιμοποιεί το τοπικό DNS. UDP και IPv6 δεν δρομολογούνται από αυτόν τον μηχανισμό. Το Driver και το routing ελέγχονται ξεχωριστά.

Πρόσθετο browser — Connect / Disconnect

Άνοιξε το MikeVas Tunnels στον browser. Η ανάγνωση και διαχείριση local tunnels χρειάζεται Manager, ακόμη και κρυμμένο στο tray. Αν είναι offline, αποθηκευμένα δημοσιευμένα server endpoints παραμένουν διαθέσιμα με μη επαληθευμένη υγεία· Start / Stop απαιτούν το app. Κάθε browser/profile έχει δικές του ρυθμίσεις και ανεξάρτητο Light / Dark.

Manage SSH tunnel → Choose tunnel: επίλεξε από το popup. Τα Start / Stop αφορούν το κοινό tunnel, όχι μόνο τον browser. Η γραμμή Tunnel στην κύρια οθόνη είναι μόνο ένδειξη.

Traffic rules: All sites via tunnel ή Selected IPs / sites. Στη δεύτερη επιλογή βάλε μία IP, CIDR ή domain ανά γραμμή. Οι IP κανόνες ταιριάζουν σε URL με κυριολεκτική IP· πρόσθεσε domain για site που ανοίγεις με όνομα.

Connect εφαρμόζει τη ρύθμιση σε όλο το συγκεκριμένο browser profile. Disconnect επιλέγει Direct μόνο για αυτόν τον browser, χωρίς να σταματά το κοινό tunnel. Όσο είναι συνδεδεμένος ο browser, αποσυνδέσου πρώτα για αλλαγή tunnel ή κανόνων. Κάνε Reload στη σελίδα για νέες συνδέσεις.

Browser connected σημαίνει επιβεβαιωμένη ρύθμιση του πρόσθετου και ενεργό tunnel. Η κινούμενη τελεία δείχνει κατεύθυνση δρομολόγησης, όχι πραγματική καταμέτρηση πακέτων. Αν το tunnel δεν επαληθεύεται, εμφανίζεται προειδοποίηση και δεν γίνεται αυτόματο Direct fallback.

Direct / Bypass και κανόνες

Bypass είναι εξαιρέσεις που βγαίνουν Direct ακόμη και όταν έχει επιλεγεί proxy. Διαχειρίζονται από Proxy Profiles → Direct / Bypass. Δεν είναι λίστα προορισμών που πρέπει να πάνε μέσα στο SOCKS.

Στο πρόσθετο το Follow app bypass είναι ενεργό από προεπιλογή. View bypass rules δείχνει τη λίστα. Αν το απενεργοποιήσεις πριν από Connect, το συγκεκριμένο browser αγνοεί αυτές τις εξαιρέσεις. Localhost / loopback παραμένουν πάντα Direct.

Οι αλλαγές στα app bypass δεν ξαναγράφουν αυτόματα ήδη εφαρμοσμένους κανόνες browser. Για νέα ρύθμιση κάνε Disconnect και Connect. Το Restore browser settings στις πληροφορίες κανόνων αφαιρεί τη ρύθμιση του πρόσθετου και επιστρέφει στις ρυθμίσεις συστήματος — δεν σημαίνει υποχρεωτικά Direct.

Master password, logout και SSH Key

Το master password ξεκλειδώνει το app και το κρυπτογραφημένο vault των SSH passwords. Δεν είναι το root/SSH password. Settings → Security → Change Master Password αλλάζει το master με ελάχιστο 8 χαρακτήρες. Κράτησέ το με ασφάλεια: δεν υπάρχει ανάκτηση ξεχασμένου master.

Automatic logout σε λεπτά αδράνειας κλειδώνει την πρόσβαση στο app, ενώ routing, tunnels και Auto Reconnect συνεχίζουν. Το login ξανανοίγει το Home. Το πλήρες Exit ή restart υπολογιστή απαιτεί νέο ξεκλείδωμα για Password tunnels.

Μετατροπή Password σε SSH Key: σύνδεσε πρώτα επιτυχώς το Password tunnel και χρησιμοποίησε τη μετατροπή της εγγραφής. Εγκαθίσταται δημόσιο key, ελέγχεται ανεξάρτητη σύνδεση με key και μόνο μετά την επιτυχημένη επανασύνδεση αφαιρείται το αποθηκευμένο password του tunnel. Το password του απομακρυσμένου χρήστη δεν διαγράφεται.

Logs και αντιμετώπιση προβλημάτων

Τα App Logs δείχνουν ενέργεια, προορισμό, αποτέλεσμα και αιτία. Τα Active Errors / Active Warnings μετρούν μόνο ξεχωριστά ενεργά προβλήματα και με κλικ δείχνουν αυτές τις εγγραφές. Το All Records κρατά όλο το διαθέσιμο ιστορικό με αναζήτηση και φίλτρα Active, Resolved, Unknown και Historical. Επαναλαμβανόμενες αποτυχίες ίδιου issue μετρούν μία φορά. Η επίλυση δεν διαγράφει το αρχικό σφάλμα.

LOCKED: κάνε master login. Authentication rejected: έλεγξε SSH username και Password / Key. Local port occupied: έλεγξε αν άλλο tunnel ή πρόγραμμα χρησιμοποιεί το port. Host key changed: επιβεβαίωσε την ταυτότητα του server πριν εμπιστευτείς νέο key.

Waiting for network / timeout: έλεγξε σύνδεση, SSH host/port και firewall. Το ACTIVE χωρίς πρόσβαση σε site χρειάζεται Destination Check προς τη σωστή υπηρεσία. Για αποκλεισμό από firewall έλεγξε την καταγραφή του firewall· μην απενεργοποιείς συνολικά την προστασία.

Manager offline στο πρόσθετο: άνοιξε το app και πάτησε Refresh. Αν άλλη επέκταση ή policy ελέγχει το proxy, η εφαρμογή δεν την παρακάμπτει. Αν υπάρχει desktop routing για τον ίδιο browser, επίλεξε έναν μηχανισμό και ακολούθησε το μήνυμα σύγκρουσης.

Clear Session καθαρίζει την προβολή συνεδρίας, όχι τα αποθηκευμένα log files. Open Log Folder και Export βοηθούν στη διάγνωση. Η διατήρηση/περιστροφή logs ορίζεται στο Settings.

Μεταφορά, ενημέρωση και όρια

Settings → Import / Export μεταφέρει ορισμούς ρυθμίσεων. Η μεταφορά αποθηκευμένων passwords είναι ξεχωριστή και κρυπτογραφημένη. Τα private keys δεν περιλαμβάνονται. Τα εισαγόμενα tunnels χρειάζονται Edit / Save με τα τοπικά credentials και έλεγχο ταυτότητας πριν ξεκινήσουν.

Στα Windows τα δεδομένα αποθηκεύονται κάτω από %LOCALAPPDATA%\MikeVas_SOCKS5, ανεξάρτητα από τον φάκελο της εφαρμογής. Το Settings → Open Settings Folder ανοίγει τον σωστό φάκελο. Αν ζητηθεί ξαφνικά νέο master password σε υπάρχουσα εγκατάσταση, μην δημιουργήσεις άλλο πριν ελεγχθεί η διαδρομή δεδομένων.

Μετά από αλλαγές του unpacked πρόσθετου κάνε Extensions → Reload σε κάθε browser. Οι υπάρχουσες ρυθμίσεις αποθηκεύονται ανά browser profile. Η μόνιμη εγκατάσταση Firefox χρειάζεται υπογραφή Mozilla· προσωρινό πρόσθετο χάνεται μετά από restart του Firefox. Αλλαγές proxy στο Firefox απαιτούν Allow in private windows.

Τα reports browser στο Home είναι πρόσφατες αναφορές, όχι λίστα ανοιχτών tabs. Μπορεί να μείνουν προσωρινά μετά το κλείσιμο browser και μετά χαρακτηρίζονται μη επιβεβαιωμένα. Δεν περιέχουν ιστορικό περιήγησης ή passwords.

Η τρέχουσα υλοποίηση διαχείρισης driver και scheduled SSH είναι για Windows. Το macOS παραμένει μελλοντικό στάδιο· δεν θεωρείται ολοκληρωμένη ή δοκιμασμένη λειτουργία.

Components και υγεία μηχανισμών

Το Components ελέγχει OpenSSH Client, .NET 10 και Python. Available σημαίνει επιτυχημένο έλεγχο, ενώ Missing ή Error χρειάζεται προσοχή. Το .NET εκτελεί το app· OpenSSH και Python χρησιμοποιούνται όταν χρειάζονται. Δεν είναι υπηρεσίες με ξεχωριστό Start. Χρησιμοποίησε την ενέργεια εγκατάστασης ή αποκατάστασης της κάρτας.

Η κάτω μπάρα δείχνει τα αποτελέσματα σε όλα τα μενού. Έλεγχος γίνεται στην εκκίνηση, κάθε πέντε λεπτά και με Check. Ο driver είναι ανεξάρτητος από το routing. Το Start with Windows ανοίγει το app στο Windows login· κάθε tunnel έχει δικό του Auto Run. Το Auto Reconnect δεν αντικαθιστά το Auto Run.

Κάτω από το όνομα του πρόσθετου φαίνεται Mechanisms healthy, Not fully verified ή Needs attention. Με κλικ βλέπεις επικοινωνία Manager/native bridge, πρόσφατους ελέγχους components, πραγματικό έλεγχο proxy του browser, συγκρούσεις και υγεία SOCKS του ενεργού tunnel. Παλιό app χωρίς στοιχεία υγείας δεν χαρακτηρίζεται υγιές. Κλειστά tunnels που δεν χρησιμοποιούνται δεν επηρεάζουν τον browser σε Direct.

Ο WinDivert εμφανίζεται πληροφοριακά: δεν χρειάζεται για SSH routing από το πρόσθετο. Το πράσινο δεν επιβεβαιώνει internet ή όλους τους προορισμούς· χρησιμοποίησε Destination Check για συγκεκριμένο στόχο. Οι έλεγχοι δεν εγκαθιστούν λογισμικό ούτε αλλάζουν αυτόματα το routing.

Παλιός τερματισμός launcher από προηγούμενη εκκίνηση Windows εμφανίζεται ως Stopped όταν το αποτέλεσμα είναι ιστορικό. Ρητά σφάλματα SSH και αποτυχίες της τρέχουσας εκκίνησης παραμένουν Error. Το αρχικό ιστορικό logs διατηρείται.

Home, This PC και Server

Το Home / Network συνδυάζει αυτόν τον υπολογιστή και τον ρυθμισμένο Linux server σε έναν χάρτη. Το This PC Overview δείχνει μόνο τοπικές πληροφορίες και το Server Overview μόνο πληροφορίες server. Πάτησε έναν κόμβο για λεπτομέρειες. Οι κινούμενες κουκκίδες δείχνουν ενδεικτικά την κατεύθυνση σύνδεσης· δεν μετρούν πραγματικά πακέτα ή ταχύτητα.

Το Application Routing αφορά εφαρμογές Windows. Το Apps & Browsers δείχνει παρατηρούμενες συνδέσεις εφαρμογών και αναφορές των πρόσθετων. Proxy Profiles και Local SSH Tunnels ανήκουν σε αυτόν τον υπολογιστή. Τα Server VPN Connections, Server SSH Tunnels και Server Logs διαχειρίζονται ανεξάρτητα τον Linux server.

Το Refresh εκτελεί αμέσως τους ελέγχους όπου παρέχεται, χωρίς αναμονή της αντίστροφης μέτρησης. Οι αυτόματοι χρόνοι ρυθμίζονται στο Settings. Server status και Server Logs έχουν ξεχωριστούς χρόνους. Ο χρόνος Driver συνεχίζει όταν αλλάζεις μενού ή κρύβεις το παράθυρο. Αποτυχημένος ή παλιός έλεγχος δεν επιβεβαιώνει υγιή σύνδεση.

Κάρτες κατάστασης και μετρητές συνδέσεων

Τα Application Routing, Proxy Profiles, Local SSH Tunnels, Server VPN Connections και Server SSH Tunnels έχουν κάρτες φίλτρων. Το All δείχνει όλες τις εγγραφές, το πράσινο Connected / Healthy τις υγιείς και το κόκκινο Disconnected / Error τις σταματημένες, αποσυνδεδεμένες ή αποτυχημένες. Το Other κρατά ξεχωριστά Starting, Reconnecting, Locked, Disabled και μη επαληθευμένες καταστάσεις και εμφανίζεται όταν χρειάζεται.

Οι αριθμοί ακολουθούν την τρέχουσα κατάσταση των γραμμών και η επιλογή φίλτρου διατηρείται στο Refresh. Το φίλτρο αλλάζει μόνο την εμφάνιση: δεν ξεκινά, σταματά ή διαγράφει συνδέσεις. Η αριστερή γραμμή δείχνει την κατάσταση. Στην επιλογή χρωματίζεται το ίδιο συνεχές περίγραμμα· το hover στα App Logs ακολουθεί την ίδια λογική χωρίς δεύτερο πλαίσιο.

Το Active applications μετρά ενεργοποιημένους κανόνες Application Routing. Το Proxy connections μετρά τις τρέχουσες TCP συνδέσεις μέσω του desktop routing και το Session total όσες δημιουργήθηκαν στην τρέχουσα εκτέλεσή του. Ενεργό routing με μηδέν συνδέσεις μπορεί να είναι φυσιολογικό όταν η εφαρμογή είναι κλειστή, αδρανής ή χρησιμοποιεί υπάρχουσα/Direct σύνδεση. Δεν μετρά όλα τα SSH tunnels ή την ανεξάρτητη κίνηση του πρόσθετου.

Διαχείριση του Linux server

Στο Connection settings συμπλήρωσε διεύθυνση server, SSH port διαχείρισης, περιορισμένο λογαριασμό, private key και επαληθευμένο known_hosts. Η πρώτη εγκατάσταση server απαιτεί ρητή προετοιμασία από διαχειριστή· το app δεν εγκαθιστά ή αλλάζει σιωπηλά έναν Linux host. Το πακέτο Windows δεν περιλαμβάνει προσωπικά management keys ή κατάλογο server.

Το Server Overview είναι πληροφοριακό. Τα VPN Connections και Server SSH Tunnels περιέχουν τις ενέργειες. Πάτησε τη γραμμή για να εμφανιστούν τα κουμπιά και ξαναπάτησέ τη ή πάτησε εκτός για να κλείσουν. Τα Start / Stop ακολουθούν την επαληθευμένη κατάσταση server. Server Auto Run σημαίνει εκκίνηση στο Linux boot και Auto Reconnect επανάληψη αποτυχημένης σύνδεσης στον Linux. Είναι ξεχωριστά από Windows startup και local tunnels.

Ένα server SSH tunnel μπορεί να εξαρτάται από server VPN. Σύνδεσε το VPN και έλεγξε το δίκτυό του πριν από το εξαρτώμενο tunnel. Επιτυχής SoftEther session δεν αρκεί: ο Linux TAP adapter πρέπει να έχει σωστή ρύθμιση και IP. Τα VPN profiles πρέπει να διατηρούν την πρόσβαση διαχείρισης και την πολιτική default gateway / DNS.

Η συμφωνημένη αρίθμηση SOCKS είναι 110xx για local και 120xx για server listeners. Το SSH port του απομακρυσμένου host είναι ανεξάρτητο. Τα νέα server tunnels ακούν σε loopback από προεπιλογή. Ένας loopback-only listener χρειάζεται SSH relay για αυτόν τον υπολογιστή. Άμεση χρήση browser απαιτεί ξεχωριστά δημοσιευμένο LAN endpoint με περιορισμό στο εγκεκριμένο δίκτυο· κάθε νέο tunnel δεν εκτίθεται αυτόματα.

Το πρόσθετο μπορεί να χρησιμοποιεί αποθηκευμένα direct server endpoints με κλειστό Manager. Τότε η ζωντανή υγεία τους δεν είναι επαληθευμένη και τα Start / Stop ή η ανάγνωση νέων ρυθμίσεων χρειάζονται Manager. Το κλείσιμο του Manager δεν σταματά Linux services. Το τοπικό Application Routing και οι local SSH relays εξακολουθούν να χρειάζονται το τοπικό app/runtime.

Διαγραφή server VPN και tunnels

Επίλεξε σύνδεση στα Server VPN Connections ή Server SSH Tunnels και πάτησε Delete. Διάβασε την επιβεβαίωση: η διαγραφή ενεργής σύνδεσης διακόπτει τους clients που τη χρησιμοποιούν. Κατά τον καθαρισμό εμφανίζεται loading popup. Αφαιρούνται μόνο πόροι του επιβεβαιωμένου server profile· τα local backup profiles και ο λογαριασμός του απομακρυσμένου προορισμού δεν διαγράφονται.

VPN δεν διαγράφεται όσο αναφέρεται ως εξάρτηση κάποιου SSH tunnel, ακόμη κι αν αυτό είναι σταματημένο. Άλλαξε πρώτα την εξάρτηση ή διέγραψε ρητά το εξαρτώμενο tunnel. Ο καθαρισμός αφαιρεί το managed service, το αποκλειστικό identity/certificate, το network profile/adapter ή τον δημοσιευμένο listener και τους δικούς του κανόνες πρόσβασης όπου υπάρχουν. Το ιστορικό logs διατηρείται.

Αν ο καθαρισμός αποτύχει στη μέση, η εγγραφή παραμένει ως μη ολοκληρωμένη διαγραφή. Επανάλαβε Delete για να τελειώσει. Restart/Edit είναι μπλοκαρισμένα για εκείνη την εγγραφή· μην αφαιρείς χειροκίνητα κοινόχρηστα αρχεία ή άσχετους κανόνες firewall.

Ενεργά σφάλματα, ιστορικό και ειδοποιήσεις

Τα App Logs ξεχωρίζουν All Records, Active Errors και Active Warnings. Το All Records κρατά όλο το διαθέσιμο ιστορικό. Οι ενεργές κάρτες μετρούν κάθε τρέχον ενεργό πρόβλημα μία φορά, χωρίς επαναλαμβανόμενους ελέγχους, επιλυμένες εγγραφές, Unknown ή Historical αποτυχίες. Με κλικ δείχνουν τις αντίστοιχες ενεργές εγγραφές. Για ιστορικό χρησιμοποίησε All Records και το φίλτρο lifecycle.

Το καμπανάκι δείχνει νέες μη αναγνωσμένες ενεργές ειδοποιήσεις, με ένδειξη This PC ή Server και χρώματα σοβαρότητας ίδια με τα Logs. Η ανάγνωση αφαιρεί την ένδειξη unread αλλά δεν επιλύει το πρόβλημα. Επιτυχής επαλήθευση μπορεί να επιλύσει issue· νέα αποτυχία μετά την αποκατάσταση δημιουργεί νέο επεισόδιο. Unknown σημαίνει ότι χρειάζεται νέος έλεγχος.

Το Open Log από ειδοποίηση καθαρίζει αντικρουόμενα φίλτρα, επιλέγει τη σχετική εγγραφή και μετακινείται σε αυτή. Το Clear Session καθαρίζει την τρέχουσα προβολή, όχι τα αποθηκευμένα log files ή το αρχικό ιστορικό. Το hover χρωματίζει το υπάρχον συνεχές περίγραμμα χωρίς δεύτερη αριστερή γραμμή.

Quick start — what connects first?

1. Open the app and log in with your master password. On first use, create a master password of at least 8 characters. Successful login opens Home.

2. In SSH Tunnels, check that your tunnel is ACTIVE. If it is STOPPED, choose Start. ACTIVE verifies the SSH process and local SOCKS listener; it does not prove every remote destination is reachable.

3. Choose one routing method: Applications for an application, or the extension for a browser. Do not enable both for the same browser. Keep the Manager available in the system tray.

SSH server, SOCKS and Destination

The SSH server is the remote computer you authenticate to using a username and SSH Key or Password. SSH port belongs to that remote service.

Local SOCKS is the tunnel's local entry point, such as 127.0.0.1:11080. Your browser or proxy profile uses this port. It is not the SSH port.

A Destination is the site or service you want to reach through the tunnel. It may be a different computer from the SSH server: browser → 127.0.0.1:11080 → SSH server → destination.

Application pages

Home / Network combines local and Linux server status. This PC Overview and Server Overview contain their own information. Application Routing controls Windows application rules; Apps & Browsers shows observed application/browser reports. Proxy Profiles manages SOCKS5 profiles and Direct / Bypass.

Local SSH Tunnels manages Windows SSH connections. The Server section separately manages VPN connections, SSH tunnels and server logs. Driver checks WinDivert; Components checks local runtimes. App Logs retains diagnostics, and Settings holds refresh, startup, notifications, security and transfer preferences.

Driver Running, Routing active and SSH ACTIVE are separate states. The driver can run without application routing. A tunnel can be ACTIVE while your browser is still Direct.

Switch Light / Dark using the sun/moon icon beside the Help book icon in the fixed header. The preference is saved immediately.

Add an SSH tunnel

SSH Tunnels → Add SSH Tunnel. Enter a name, unique Local SOCKS port, SSH host, SSH port and SSH username. Password authenticates that username, for example root.

Choose SSH Key with a private key path, or Password. Save validates authentication and sets up tunnel management. If Trust & Continue appears, verify the fingerprint through a trusted source first. Do not accept an unexplained host key change.

Start after saving starts the connection immediately. Auto Run and Auto Reconnect are separate options. Do not reuse a local port for two tunnels or another application.

Start / Stop / Restart and checks

Start launches the shared SSH tunnel. Stop stops it for everyone using it. Restart disconnects and starts it again. Buttons are enabled according to the current state.

Test Connection rechecks tunnel status. Destination Check tests a specific IP and TCP port through SOCKS: it verifies TCP reachability, not a complete website response or login. When configured, it is rechecked about once a minute during active tunnel checks.

Browser Stop Protection On prevents Stop from the extension. Desktop Stop remains available. Last healthy is the last known successful check, not a guarantee the tunnel is still active.

What runs automatically

Proxy Profiles checks enabled profiles at the interval set in Settings. Home refreshes periodically while open. Driver has its own countdown that continues when you change menus or hide the app.

Local Windows tunnels have their own supervisor and SOCKS checks. With Auto Reconnect they retry after network failures. Delays increase from the configured initial value up to 10 minutes, or a larger configured base, and reset after 60 seconds of stable connection. Server service retry behavior is managed separately on Linux.

While waiting for the network, reachability is rechecked every 5 seconds. A long monitoring gap, such as sleep, triggers a new SSH server reachability check. Loss of an established SSH session also relies on OpenSSH keepalives and is not detected instantly.

Authentication failure, unknown/changed host key, private key problems, SSH configuration/algorithm failures and local port conflicts pause retries. Correct the cause and press Start. Each tunnel is protected against duplicate starts.

New supervisor versions load on the next Start / Restart of each tunnel. They do not replace an already running supervisor mid-connection.

Windows startup, Auto Run and tray

Settings → Start with Windows starts the app. Start minimized puts it in the tray. Each SSH tunnel's Auto Run is separate and determines whether that tunnel starts at Windows login.

An SSH Key without a passphrase can start without master login when the key and task are ready. Password tunnels need the app's unlocked vault; until then they wait in LOCKED. Auto Reconnect does not enable Auto Run.

X hides the app to the tray. Exit really closes it. Independent scheduled SSH tunnels may keep running, but the extension cannot Start / Stop or fetch fresh status without the Manager. Existing browser routing rules remain configured.

Applications and Proxy Profiles

Proxy Profiles → Add Proxy Profile: enter the SOCKS5 host and port. For a local SSH tunnel, these are normally 127.0.0.1 and the Local SOCKS port. A profile's OK status checks the SOCKS endpoint.

Applications → Add Application: select an executable and proxy profile. Connect enables routing for that application. Optionally specify IPs/networks to send through the proxy; other destinations stay Direct.

You can create differently named entries for the same executable. When another entry is active, Cancel / Switch checks the new proxy before changing routing. This does not give two simultaneous instances of the same executable independent profiles.

Check Connection presents diagnostics without starting a tunnel. Desktop routing covers TCP/IPv4 and uses local DNS. UDP and IPv6 are outside this routing mechanism. Driver and routing are controlled separately.

Browser extension — Connect / Disconnect

Open MikeVas Tunnels in the browser. Local tunnel discovery/control requires the Manager, including hidden in tray. If it is offline, previously saved published server endpoints remain available with unverified health; management Start / Stop requires the app. Each browser/profile has separate settings and an independent Light / Dark preference.

Manage SSH tunnel → Choose tunnel: select an entry in the popup. Start / Stop affects the shared tunnel, not just this browser. The main Tunnel row is read-only.

Traffic rules offers All sites via tunnel or Selected IPs / sites. For selected sites enter one IP, CIDR or domain per line. IP rules match literal IP URLs; add domains for sites you access by name.

Connect applies routing throughout this browser profile. Disconnect chooses Direct only for this browser and keeps the shared tunnel running. Disconnect before changing the tunnel or routing rules. Reload web pages to establish new connections.

Browser connected describes the applied browser proxy routing. For saved server endpoints with the Manager offline, remote service health remains unverified. The moving dot illustrates routing direction; it is not a live packet counter. An unverified tunnel shows a warning and does not trigger automatic Direct fallback.

Direct / Bypass and rules

Bypass entries are exceptions that use Direct even when a proxy is selected. Manage them in Proxy Profiles → Direct / Bypass. They are not the list of destinations to send through SOCKS.

The extension's Follow app bypass is enabled by default. View bypass rules displays the list. Uncheck it before Connect to ignore those app exceptions in this browser. Localhost / loopback always stays Direct.

Changing app bypass does not automatically rewrite an already applied browser policy. Disconnect and Connect to apply the new snapshot. Restore browser settings in rule information removes this extension's settings and returns to system settings; that is not necessarily Direct.

Master password, logout and SSH Key

The master password unlocks the app and encrypted SSH password vault. It is not your root/SSH password. Settings → Security → Change Master Password changes it, with a minimum of 8 characters. Keep it safe: a forgotten master password cannot be recovered.

Automatic logout after inactivity locks app access while routing, tunnels and Auto Reconnect continue. Login returns to Home. Full Exit or a computer restart requires a fresh unlock for Password tunnels.

To convert Password to SSH Key, first connect the Password tunnel successfully and use its conversion action. The public key is installed, independent key authentication is verified, and the saved tunnel password is removed only after successful reconnection. The remote user's password is not deleted.

Logs and troubleshooting

App Logs shows operation, destination, result and reason. Active Errors / Active Warnings count distinct active issues only; clicking shows those active records. All Records retains full available history with search and lifecycle filters: Active, Resolved, Unknown and Historical. Repeated failures of the same issue are counted once. Resolution never deletes the original error.

LOCKED: log in with the master password. Authentication rejected: check SSH username and Password / Key. Local port occupied: check for another tunnel or program using that port. Host key changed: verify server identity before trusting the new key.

Waiting for network / timeout: check connectivity, SSH host/port and firewall. ACTIVE without website access calls for a Destination Check to the correct service. Review firewall logs for blocks; do not disable all protection.

Manager offline in the extension: start the app and choose Refresh. Another extension or policy controlling the proxy is not overridden. If desktop routing is active for the same browser, select one routing method and follow the conflict message.

Clear Session clears the session view, not saved log files. Open Log Folder and Export help diagnosis. Settings controls log retention and rotation.

Transfer, updates and current limits

Settings → Import / Export transfers configuration definitions. Saved password transfer is separate and encrypted. Private keys are not included. Imported tunnels require Edit / Save with local credentials and identity verification before starting.

On Windows, data is stored under %LOCALAPPDATA%\MikeVas_SOCKS5, independently of the application folder. Settings → Open Settings Folder opens the correct location. If an existing installation suddenly asks for a new master password, do not create another before checking its data location.

After unpacked extension updates, use Extensions → Reload in each browser. Settings are stored per browser profile. Permanent Firefox installation requires Mozilla signing; a temporary add-on is removed by Firefox restart. Firefox proxy changes require Allow in private windows.

Browser reports on Home are recent reports, not a list of open tabs. They can remain briefly after a browser closes, then become unverified. They contain no browsing history or passwords.

The current driver and scheduled SSH management implementation targets Windows. macOS remains a future stage and is not a completed or verified implementation.

Components and mechanism health

Components checks OpenSSH Client, .NET 10 and Python. Available means the component was verified; Missing or Error requires attention. .NET runs this app, while OpenSSH and Python run on demand. They are not services with separate Start buttons. Use the installation or repair action shown on the component card.

The bottom status bar shows component results on every page. Checks run at startup, every five minutes and when you choose Check. Driver state is separate from routing. Start with Windows launches the app at Windows sign-in; each tunnel has its own Auto Run setting. Auto Reconnect does not replace Auto Run.

The browser extension shows Mechanisms healthy, Not fully verified or Needs attention under its name. Click the indicator for Manager/native bridge, component freshness, effective browser proxy control, conflicts and the active tunnel SOCKS health. An old Manager without health data is not marked healthy. Stopped tunnels not in use do not make a Direct browser unhealthy.

WinDivert is shown for information: browser extension SSH routing does not require it. Green health does not prove internet access or every destination; use Destination Check for a specific target. Local checks do not install software or change routing automatically.

A stopped launcher from an earlier Windows session is shown as Stopped when its termination result is historical. Explicit SSH errors and failures in the current session remain Error; the original log history is retained.

Home, This PC and Server

Home / Network combines this computer and the configured Linux server in one map. This PC Overview shows only local information; Server Overview shows only server information. Select a map node to inspect its details. The moving dots illustrate the connection direction; they are not a live packet or throughput measurement.

Application Routing applies to Windows applications. Apps & Browsers shows observed application connections and reports from installed browser extensions. Proxy Profiles and Local SSH Tunnels belong to this computer. Server VPN Connections, Server SSH Tunnels and Server Logs manage the Linux server independently.

Refresh runs the checks immediately where offered, without waiting for the countdown. Automatic intervals remain configurable in Settings. Server status and Server Logs have separate intervals. The driver schedule continues across menu changes and while the window is hidden. A failed or stale check is not evidence of a healthy connection.

Status cards and connection counters

Application Routing, Proxy Profiles, Local SSH Tunnels, Server VPN Connections and Server SSH Tunnels have clickable status cards. All shows every entry; green Connected / Healthy shows healthy entries; red Disconnected / Error shows stopped, disconnected or failed entries. Other keeps starting, reconnecting, locked, disabled and unverified states separate. It appears when needed.

Counts follow the current row states, and the selected filter survives Refresh. Filtering changes only what is displayed: it does not start, stop or delete connections. A left colored accent indicates state. Selection colors the same continuous card outline; hover in App Logs uses the same outline without a second frame.

Active applications counts enabled application-routing rules. Proxy connections counts current TCP relays through desktop Application Routing; Session total is the number established during that routing session. Enabled routing with zero relays can be normal when the application is idle, closed or using an existing/direct connection. These counters do not count all SSH tunnels or independent browser-extension traffic.

Managing the Linux server

Configure the server address, SSH management port, restricted management account, private key and verified known_hosts file in Connection settings. A first server installation requires explicit administrator provisioning; the app does not silently install or reconfigure a Linux host. The Windows release does not include your management keys or server catalogue.

Server Overview is informational. VPN Connections and Server SSH Tunnels are the control pages. Click a row to show its controls and click it again or outside it to collapse. Start / Stop availability follows the verified server state. Server Auto Run means startup when Linux boots; Auto Reconnect retries a failed connection on Linux. Those settings are separate from Windows startup and local tunnels.

A server SSH tunnel can depend on a server VPN. Establish the VPN and its network configuration before testing the dependent tunnel. A completed SoftEther session alone is insufficient: the Linux TAP adapter must be correctly configured and have an address. Server VPN profiles must preserve management access, default gateway and DNS policy.

The agreed port ranges are 110xx for local SOCKS listeners and 120xx for server listeners. The remote SSH port is independent. New server tunnels listen on loopback by default. A loopback-only server listener needs an SSH relay for use on this computer. Direct browser use needs a separately published LAN endpoint restricted to the approved source network; the app does not automatically expose every new tunnel.

In the extension, saved direct server endpoints remain usable while the Manager is closed. Their live health is then unverified, and Start / Stop and configuration discovery still require the Manager. Closing the Manager does not stop Linux services. Local Windows application routing and local SSH relays still depend on the local app/runtime.

Deleting server VPNs and tunnels

Choose a connection in Server VPN Connections or Server SSH Tunnels, then Delete. Read the confirmation: deleting an active connection interrupts clients that use it. The app displays a loading popup during cleanup. Deletion removes only resources owned by the confirmed server profile; local PC backup profiles and the remote destination account are not deleted.

A VPN cannot be deleted while an SSH tunnel references it, even when that tunnel is stopped. First change the dependency or explicitly delete the dependent tunnel. Server cleanup includes the managed service, dedicated identity or certificate, network profile/adapter or published listener and its owned access rules where applicable. Original log history is retained.

If cleanup fails midway, the entry remains visible as an incomplete deletion. Retry Delete to finish cleanup. Restart/edit are blocked for that entry; do not manually erase shared files or delete unrelated firewall rules.

Active errors, retained logs and notifications

App Logs separates All Records from Active Errors and Active Warnings. All Records retains the complete available history. The active cards count distinct currently active problems once each, not repeated checks, resolved records, unknown issues or historical failures. Clicking an active card shows those matching active records. Use All Records and the lifecycle selector to inspect history.

The header bell shows new unread active notifications, with This PC or Server scope and severity colors matching Logs. Marking a notification read clears its unread indicator but does not resolve the problem. Successful verification can resolve an issue; a failure after recovery creates a new episode. Unknown means a fresh check is still required.

Open Log from a notification clears conflicting filters, selects the matching record and scrolls to it. Clear Session clears the current log view, not saved log files or the original retained history. Hover highlights the existing continuous card outline; it does not add another left status line.
