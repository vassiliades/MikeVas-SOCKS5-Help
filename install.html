Portable application

1. Download the Windows ZIP from the **private repository's Releases** page. Compare

its SHA-256 with `SHA256SUMS.txt` before extracting it.

2. Extract the complete ZIP into a permanent folder, for example

`%LOCALAPPDATA%\Programs\MikeVas-SOCKS5`. Keep all files together. Do not run inside ZIP.

3. Run `Setup.cmd` once as your normal Windows user. It registers only this user's

native messaging host for supported browsers and creates a desktop shortcut.

It does not start SSH, install a driver, change a firewall or change proxy settings.

4. Open `MikeVas_SOCKS5.exe`, create your own master password, then configure your

SSH tunnels and proxy/application rules. The release contains no personal configuration.

5. OpenSSH must exist at `%WINDIR%\System32\OpenSSH\ssh.exe`. If missing, install

**OpenSSH Client** from Windows Optional Features, or run the optional

`Install-OpenSSH.cmd` as Administrator. This script changes a Windows capability;

it is never run automatically by Setup.

The .NET runtime and Python embeddable runtime are bundled. No SDK, pip, SecureCRT,

Node.js or separate Python installation is needed to run this ZIP.

The EXE is not publisher-code-signed. The original bundled WinDivert driver is

unchanged. Driver/routing operations request administrator approval separately.

Do not disable Windows or antivirus protection to install the app.

Browser extensions

The browser extension requires the Manager running, including minimized in tray.

The stores do not install the native app for you. Firefox store packages need Mozilla

review/signing before normal permanent installation. Store ZIPs are **upload inputs**,

not signed installable browser packages.

Data and updates

Data is under `%LOCALAPPDATA%\MikeVas_SOCKS5`, separate from the application folder.

Never distribute this folder, SSH private keys, known_hosts, logs or exported passwords.

Retain your master password: it cannot be recovered.

For an update, Exit the Manager and close the extension popup, then replace application

files in the **same permanent folder**. Existing settings and encrypted vault remain in

the data folder. Existing SSH tasks point to runtime/key paths: do not move an installed

folder after enabling Auto Run without re-saving the affected tunnel definitions.

The app's Start with Windows setting and each tunnel's Auto Run are separate.

Public Help: https://vassiliades.github.io/MikeVas-SOCKS5-Help/

Removal

Choose Disconnect/Direct in the extension (or Restore browser settings) before removing

it. Stop routing in the app. Remove managed SSH tunnels from SSH Tunnels if you want

their tasks removed. Setup's native host registration can be removed from the current

user's `Software\<browser vendor>\NativeMessagingHosts\com.mikevas.socks5` keys.

Do not remove another app's registry keys, SSH keys or tasks. Removing the portable

folder does not delete saved data, SSH tasks, startup entries or the driver service.

Components and status

Open Components to check execution/version of OpenSSH Client, .NET 10 and Python.

Missing OpenSSH Client can be installed there with administrator approval. Python repair

instructions refer to restoring the complete app ZIP. Runtimes are not services to Start.

Bottom-bar results refresh at startup, every five minutes and with Check.

The extension's mechanism indicator opens detailed local checks. It distinguishes an

offline Manager, unverified/old checks, proxy-control conflicts and an unhealthy active

tunnel. Stopped unused tunnels are not failures for a Direct browser. WinDivert is not

required for extension-only routing. No destination/internet guarantee is implied.
